## `> about_me`

I'm a developer focused on **Java, Minecraft infrastructure and networking systems**.

I enjoy taking complex systems apart, understanding how they work, and rebuilding them with a cleaner architecture.

Currently working around:

* Minecraft server infrastructure
* Java networking
* Netty pipelines
* Protocol design
* Custom server software
* Client architecture
* Performance & reliability
* Security-oriented transport design

I prefer systems that are **measurable, testable and maintainable** over systems that simply "work".

## `> architecture`

One of the things I enjoy most is understanding what happens underneath the API.

```text
Application
     │
     ▼
Protocol
     │
     ▼
Transport
     │
     ▼
Netty
     │
     ▼
TCP
     │
     ▼
Operating System
```

For Minecraft networking, that means working with things like:

```text
TCP
 ↓
Netty Channel
 ↓
Pipeline
 ↓
Decoder / Encoder
 ↓
Packet Layer
 ↓
Minecraft Protocol
 ↓
Server Logic
```

The goal isn't just to add another feature.

The goal is to understand the entire path.
